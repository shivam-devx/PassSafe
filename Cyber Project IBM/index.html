    Password Security Tips

    • 🔒 Use long passwords — at least 12 characters.
    • 🚫 Avoid common words, names, and predictable patterns like "123456".
    • 🔁 Never reuse the same password across different accounts.
    • 🗝 Use a password manager to store passwords safely.
    • ✅ Enable two-factor authentication (2FA) wherever possible.
